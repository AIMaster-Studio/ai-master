# 商业假设一页纸

状态：2026-09-05 的待验证方案，无已签客户、收入或转化率结论。

**使用者与问题。** 首批验证对象是正在学习大模型通识与 RAG 入门的大学生。假设他们需要短任务、可理解的纠错和持续复习记录；教师需要知道学生在哪些概念上反复出错。访谈要验证实际学习过程和现有替代方式，不能只问是否喜欢页面。

**价值与购买方。** 产品提供讲解、独立测验与记录的工作流。潜在购买方是课程组织方或教学团队，学生自费是另一条尚未验证的路径。教师认可、学生愿用与预算负责人愿付费是三个不同证据。

**最小交付。** 先围绕已审校的核心模块提供课程实践工具、任务配置与教学支持。现阶段为本机原型，多人云部署、教师班级管理和服务承诺需另行实现，不能写进已交付功能。

**商业化前提。** 上游 dsh-pet README 明确禁止动画、提示词与源视频素材商用。现有形象和全部动作保留；任何收费服务或商业推广前，先取得覆盖具体场景的书面授权，并核清角色、字体及其他素材权利。未完成授权时，不把当前素材纳入可销售权益，也不承诺现有原型可直接商用。

**成本模型。** 每期总成本 = 模型输入用量 × 输入单价 + 输出用量 × 输出单价 + 服务资源 + 内容审校工时 × 工时成本 + 教师支持 + 授权费用。模型单价按实际提供商和日期填写，缓存折扣只在满足其规则时计算。本地练习无模型调用费，但仍有维护与内容成本。

**验证步骤与停止条件。**

1. 访谈真实学习者、教师与预算负责人，记录现有做法、重复任务和失败案例。若问题不集中，收窄或更换场景。
2. 开展经同意的课程试点，观察独立完成、纠错利用和下一次自发使用；单纯访问量不算持续价值。
3. 记录每次学习的模型用量与支持工时，测算单位服务成本。若人工服务无法随人数承受，先修订交付方式。
4. 完成授权和必要部署能力后，以明确交付范围验证真实付费意愿；口头称赞不计作订单。
5. 将续用与学习效果分开评估。若双闸流程造成明显负担且没有可观察收益，缩短或调整任务，暂停扩张。

**目前不填的数字。** 市场规模、收入预测、获客成本、付费转化、留存与利润均等待可追溯依据。参赛、AI 行业热度和同类产品估值不能替代本项目商业验证。
