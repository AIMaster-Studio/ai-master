# 商业假设与验证记录

状态：2026-09-06。本文区分当前原型证据、商业假设和待实施验证；没有已签客户、收入、真实用户留存或教育效果结论。

## 1. 使用者与问题

首批验证对象是正在学习大模型与 RAG 入门知识的大学生，使用场景是课程实践或自主练习。我们要验证的具体问题是：学生看完材料后能否用自己的话解释关键概念，教师能否低成本发现反复出错的概念，而不是仅获得一个流畅的聊天回答。

教师认可、学生愿用、预算负责人愿意付费是三类不同证据。访谈须记录现有做法、失败案例和替代工具，不能只问“是否喜欢页面”。

## 2. 当前可复核的差异化

以下是实现层面的差异点，不是对竞品功能的绝对断言。学习通、雨课堂等产品的具体能力和账号要求仍需按同一场景实测比较。

| 维度 | AI Master 当前原型 | 代码证据与边界 |
| --- | --- | --- |
| 输出验收 | 学习者先用自己的话提交讲解；本地进行七项完整性筛查，配置模型后可增加结构化复评 | [learning-core.js](../../frontend/static/js/learning-core.js) 的 `screenExplanation`；本地规则是启发式检查，不保证语义正确，模型失败时标记 `fallback-local` |
| 进度闸门 | 当前讲解通过且配套客观测验达到 75%，两者都满足才记录模块通关 | [server/index.js](../../server/index.js) 的 `complete` 路由；目前重点建设 7 个核心模块，不把 57 个课程节点说成 57 个独立通关题库 |
| 本机可演示与开源边界 | Node.js 本机服务 + SQLite 保存学习记录；代码以 MIT 发布，未配置模型时可走本地练习路径 | [README.md](../../README.md) 启动说明；本机原型不等于云部署、跨设备账号或商用交付，MIT 代码许可也不覆盖受限的鲸鱼娘素材 |

这三点构成待验证的价值主张：相比只提交作业或只进行对话，强制讲解、独立验收和可复查记录是否能让学生更愿意修订，并让教师减少重复判断工作。只有对照场景试点后，才能声称有竞争优势。

## 3. 三层商业路径

这是分层假设和验证顺序，不是已交付功能或已确认价格。教师后台、错误概念热力图、多人班级管理和企业私有知识库目前均属于后续产品范围。

| 客户层 | 假设交付物 | 收费逻辑（待验证） | 关键前置条件与验证 |
| --- | --- | --- | --- |
| 高校 B 端（主路径） | 7 个核心模块的课程实践包、讲解验收流程、基础学习记录；后续再评估教师班级视图和概念错因汇总 | 按院系或课程授权的年费制，避免先按学生人头计费 | 访谈任课教师和预算负责人；用小范围课程试点验证部署、备课和支持工时，取得授权后再谈报价 |
| 企业 B 端（次路径） | 定制课程任务、私有部署方案、企业内部知识库 RAG 实验环境（规划） | 项目实施费 + 年维护费，价格由部署、内容审校和支持范围决定 | 先确认数据隔离、部署、知识库接入和服务等级要求；当前原型尚未交付这些能力 |
| C 端长尾 | MIT 代码核心、本地练习、内容包或部署支持（规划）；模型调用由用户自带合规 API 配置 | 免费核心 + 付费内容/部署/支持的 Freemium 假设 | 核对模型提供商条款、支付与支持成本；不把“API key 代充”写成当前已有商业能力，也不绕过服务商限制 |

鲸鱼娘形象及现有动作继续保留，用于学习状态反馈和陪伴呈现。\`third_party/dsh-pet/dsh-pet\` 的代码许可与素材许可不同：上游说明动画、提示词和源视频禁止商用。任何收费服务、商业宣传或商业分发前，必须取得覆盖具体场景的书面授权，并将授权费用计入成本；未完成前不承诺原型可直接商用。

## 4. 成本模型（情景估算）

当前没有 API 用量记录或真实账单，以下只用于判断量级，不是已验证的 DeepSeek 报价，也不包含人工和授权成本。实际计算应以所选模型、地区、日期和账单为准。

| 情景 | 调用假设 | 计算方式 | 结果解释 |
| --- | --- | --- | --- |
| 本地练习 | 不调用远程模型 | 0 × 模型调用单价 | 无远程调用费，但仍有维护、内容审校、设备和支持成本 |
| 远程复评示例 | 每次约 500 token 输入 + 200 token 输出；单价以实际账单替换 | `500 × 输入单价 + 200 × 输出单价` | 当前代码发送的上下文包含系统提示、任务、概念、课程摘要和学生文本，token 数尚未实测；`max_tokens` 上限为 900，不能把 200 当成已观测值 |
| 学期量级示例 | 57 个课程节点 × 每节点 2 次复评 = 114 次 | `114 × 单次成本` | 57 是课程节点总数，当前只有 7 个核心模块进入重点通关流程；该算式是上限情景，不是学生真实行为 |

例如，若经账单核实单次调用成本为 `¥0.001`，则 114 次约为 `¥0.114`；这个数字只说明模型调用的一个情景量级，不能据此宣称总边际成本低于 `¥0.5/生/学期`。完整单位成本还应加入服务资源、内容审校工时、教师支持、支付费用、授权和部署维护，并记录每次请求的实际用量。

## 5. 证据状态与下一步

| 假设 | 当前状态 | 最小验证与停止条件 |
| --- | --- | --- |
| 学生愿意为“自己讲解 + 验收”投入额外时间 | 仅有可演示流程 | 取得同意后做 2 周可用性试点，记录完成率、修订率、任务耗时和主动复习；若负担明显且无可观察收益，缩短任务或暂停扩张 |
| 教师能从记录中减少重复判断 | 未验证 | 访谈 3–5 位 AI 相关课程教师，记录真实案例和现有耗时；至少安排一次带任务的原型试用，不能用口头称赞替代 |
| 高校院系愿意承担年费 | 未验证 | 访谈教师与预算负责人，确认采购主体、交付范围和预算周期；没有报价接受、合同或采购流程证据，不填写成交价 |
| 企业需要私有 RAG 培训环境 | 未验证，能力也未交付 | 先做需求访谈和部署边界清单；无法满足数据、部署和支持要求时，不承诺企业方案 |
| 模型调用成本可承受 | 只有情景算式 | 接入用量记录或逐笔账单，按真实输入/输出 token、失败重试和并发计算；若人工与授权成本占主导，优先调整交付方式 |
| 鲸鱼娘能提高坚持度且可商业使用 | 坚持度未验证，商业授权未完成 | 试点中把角色反馈与任务行为分开记录；取得书面授权前不进行商业化承诺 |

### 访谈记录模板（待填写）

每位受访者单独记录并脱敏：日期、课程类型、角色（教师/预算负责人）、现有判断流程及耗时、学生常见错误、对“提交自己的讲解并自动反馈”的具体反应、愿意试用的条件、明确拒绝的原因。不得把未发生的访谈写成样本或百分比。

### 最小试点记录模板（待实施）

在取得参与同意并完成脱敏说明后，记录班级规模、试点周期、使用版本和以下指标定义：节点/模块完成率、首次讲解通过率、平均讲解有效字符数、修订后通过率、客观题通过率、任务耗时、7 日内再次使用率及退出原因。小班两周数据只能说明可用性和使用行为，不能当作学习效果；教育效果需另按 [education-study-plan.md](education-study-plan.md) 的前测、延迟迁移任务和盲评方案实施。

## 6. 答辩口径（基于当前证据）

“商业上我们先验证三件事：第一，当前原型把自己的讲解、七项本地筛查、客观题 75% 门槛和本机记录连成了可演示流程；第二，模型调用成本可以先用实际账单和用量记录测算，本地练习则不产生远程模型调用费；第三，收入路径按高校课程授权、企业定制部署、开源增值服务分层验证。现在没有已签客户、真实营收、教师访谈或试点结果，因此我们把这些列为下一步验证，而不是已实现的商业成绩。”

不填写无依据的市场规模、收入预测、付费转化、留存、利润或加分数字；不把自动化测试、合成档案和鲸鱼娘素材许可扩大解释为真实用户或商业授权证据。
