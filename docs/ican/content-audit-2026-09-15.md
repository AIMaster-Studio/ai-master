# 课程事实审校报告（2026-09-15）

本报告落实 `facts-and-limits.md` 中「课程事实审校队列」的七项，并回答一个此前没有明确答案的问题：
**这些说法到底在哪些文件里、以什么身份出现（事实陈述 / 已标注的误区 / 审校备注）。**

---

## 一、方法与口径

- **依据**：官方文档或原始论文。每一项都记录核实日期与适用版本。
- **不采信**：二手博客、聚合站、模型记忆。
- **处理方式**分四类：
  - **修正**：内容与原始来源冲突，已改。
  - **确认**：与原始来源一致，保留。
  - **降级**：无法核实到原始来源，改为不主张 / 不给数字。
  - **登记**：保留但标注为待复核。
- **硬规则**（本次已变成可执行测试）：**凡未核实的数字，一律不得进入客观题标准答案。**

### 一个关键发现：同一说法在不同文件里的身份不一致

`knowledge-cognitive-map.json` 是一份**诚实的**审校标注文件，它对队列里的每一项都写了
`contentStatus: "present-needs-fact-check"` 与 `contentCaveat`，例如：

| 认知地图条目 | caveat 原文 |
| --- | --- |
| 1_2 Token 与 Tokenization | 纠正最小语义单位的过强定义；中英文 token 比例依 tokenizer 与文本变化 |
| 3_2 角色扮演提示法 | 不采用角色会激活特定子网络的未经核实机理解释 |
| 4_x 框架与 API | 直接 API 并非只能单轮；示例应对照当前框架版本 |

**问题在于**：`knowledge_graph.json`、`galaxy_data.json`、`knowledge_data.json`
这三个文件里，同样的说法仍然是**不带任何标注的事实陈述**。也就是说，
审校结论只落到了认知地图，没有同步到实际展示给学习者的知识图谱。
这是本次审校最实质的发现——不是「说错了」，而是「同一个项目里两个地方说法互相矛盾」。

### 3. 「将 token 定义为最小语义单位」

**这是本次最严重的一处，因为项目内部自相矛盾。**

| 位置 | 原文 | 身份 |
| --- | --- | --- |
| `learning-curriculum.json` | `token(就是\|等于)(一个汉字\|一个单词\|最小语义单位)` → 列入 **misconceptions**，反馈为「token 的粒度取决于分词器，不固定等于一个字、词或语义单位」 | **正确**（误区表） |
| `knowledge_graph.json` | 「Token 是 LLM 处理文本的最小语义单位。」 | **错误**（事实陈述） |
| `galaxy_data.json`（2 处） | 同上 | **错误** |
| `knowledge_data.json` | 同上 | **错误** |

也就是说：**通关测验把「token 是最小语义单位」判为错误答案，而知识图谱把它当事实教。**
学习者若照着图谱答题，会在测验里被判错。

**处理：修正**。三份文件统一改为：

> Token 是 LLM 处理文本的基本单位，由 Tokenizer（分词器）把文本映射为整数序列得到。
> 它**不等于固定的语义单位**：同一个词可能被切成多个 token，不同分词器对同一段文本的切法也不同。

### 4. 提示效果倍数

| 说法 | 位置 | 结论 |
| --- | --- | --- |
| 「同一模型，不同提示词，输出质量差异可达 10 倍以上」 | `chapter_03.json` | **降级** |
| 「好的提示词能让小模型（7B）超越差提示词下的大模型（175B）」 | `chapter_03.json` | **降级** |

理由：「输出质量」不是一个可测量量，没有定义就没有倍数；「10 倍以上」无任何来源。
后一条是绝对化表述，其成立与否取决于任务难度、评测口径与两者版本，不存在通用结论。

**处理：改为不主张、不给数字**，并写明为什么不给：

> 同一模型、不同提示词，在具体任务上的表现差异可以很大；但「提升几倍」取决于任务、
> 评分口径与模型版本，**没有通用倍数，本节不给数字**。

### 5. 角色提示可激活特定子网络

| 位置 | 原文 | 身份 |
| --- | --- | --- |
| `knowledge-cognitive-map.json` | caveat：「不采用角色会激活特定子网络的未经核实机理解释」 | **正确** |
| `knowledge_graph.json` | 「模型会调用其参数空间中与角色相关的子网络」 | **错误**（事实陈述） |
| `galaxy_data.json`（2 处） | 同上 | **错误** |

**处理：修正**。改为只陈述可观察效果，明确不作机理解释：

> 给模型设定角色会改变输出的用词与语气分布，这是提示词层面的可观察效果。
> 至于「模型是否因此激活了参数空间中某个专门的子网络」，目前没有可核实的机理解释，本节不作此主张。

现在已变成会失败的测试（见下）。

### 已变成可执行测试

新增 `tests/content-audit.test.js`（5 项）：

1. 扫描器自身有效性 —— 题目数下限 + 每题的 `answer` 必须是合法下标
   （防的是「扫描器坏了所以永远通过」这一最常见的守卫失效方式）；
2. 题库中出现任何量级性数字，必须登记在 `VERIFIED_NUMBERS`（含依据与核实日期），否则失败；
3. 反向检查 —— 登记了却已不在题库里的条目必须删除，防止清单腐烂成假账；
4. 本次修正的五处缺陷不得被改回去；
5. 认知地图里那三条 caveat 不得被删掉。

## 六、这份报告不能证明什么

- 它**只覆盖审校队列里的七项**，不是全量内容审校。57 个课程节点中仍有大量内容未经逐条核对。
- 「确认」表示与所引原始来源一致，**不表示**该说法在教学上恰当或表述无歧义。
- 官方文档核对的是**当期版本**（2026-09-15）；工具类内容会继续变化，需定期重核。
- 本报告的数字扫描只覆盖**客观题题库**；正文与知识图谱中的数字尚未纳入自动扫描，
  第三节的「0」仅指答案键风险面。
