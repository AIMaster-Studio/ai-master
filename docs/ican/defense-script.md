# 五分钟答辩稿

以下口播按正常语速约五分钟。方括号是现场动作，不朗读。提前打开学习工作台，准备一个专用访客档案；所有展示记录都由现场或彩排真实操作产生。演示 RAG 前，在彩排中实际完成 `llm-basics` 与 `prompt-design` 两项先修，保留记录并说明是彩排产生，不修改数据绕过锁定。从全新档案开始时应改演示无先修的“大模型如何生成回答”。未接入模型时全程使用“本地练习”称呼。

## 0:00–0:40：问题与对象

各位评委好，我们的项目是 AI Master，面向学习大模型与 RAG 入门知识的大学生。

我们关注一个具体问题：学习者看完教程，常常还说不清概念，也无法判断自己能否运用。AI 对话可以给出流畅答案，但替学习者说出答案，并不等于学习者已经学会。因此，我们把本次创新集中在“讲解通关”：学习之后先自己解释，再接受客观题验收，留下可以回看和复习的记录。

## 0:40–1:20：展示学习入口

[进入学习工作台，展示目标与基础诊断，选一个核心模块。]

这是今天可以实际运行的本机原型。学习者先做基础诊断，选择学习目标和节奏，再进入具体任务。原有十章、五十七个课程节点继续保留；其中七个核心模块进入了这次重点建设的通关流程。我们没有把全部课程节点都说成已完成能力认证。认知地图为每个节点标明目标、任务和需要收集的证据，属于团队教学设计，尚未经过效果验证。

## 1:20–2:30：演示双重验收

[打开 RAG 相关模块，展示学习内容；先提交一句空泛或重复回答，再展示纠错提示。随后输入自己组织的有效解释。]

以 RAG 为例，学习者要解释：系统如何找到资料，怎样把证据交给模型，以及没有证据时应该怎么办。输入很长，或重复几个关键词，不应自动获得通关。系统先检查讲解是否满足当前规则；配置模型后，才会增加结构化的 AI 复评。没有配置或调用失败，界面会明确显示本地练习或降级状态。

[完成本模块客观题。故意保留一题错误，展示得分与纠错；必要时按页面条件修订重试。]

讲解通过也不是终点。客观题按预设正确答案独立判分，至少达到百分之七十五，并且讲解条件满足，才记录通关。模型不能直接修改客观题答案或授予通关。这里的通关表示达到本原型的规则，不等同于长期掌握，也不是防作弊考试认证。

## 2:30–3:15：记录与复习

[展示错题或复习区，刷新页面，再导出当前记录。]

这些尝试和结果保存在本机数据库，刷新之后可以继续。学习者能看到错题和复习安排，也可以导出自己的记录。我们希望把反馈从一句“答得不错”，变成哪里答错、如何修订、何时再练的连续过程。间隔复习的教育效果需要后续研究，现在不会用页面完成率代替学习收益。

## 3:15–4:00：创新与视觉资产边界

[展示鲸鱼娘响应学习状态；无需切换全部动作。]

我们的工作是在现有课程和交互基础上，组织讲解、确定判题与持久记录，形成可检查的学习流程。它不是新基础模型，也不是仅凭新的教学术语就成立的创新。后续是否优于普通课程和聊天助手，需要对照研究。

鲸鱼娘用于学习陪伴与状态反馈，原形象和全部已有动作均保留。我们明确承认第三方来源：上游代码采用 MIT 许可，但上游 README 对动画等素材写明禁止商用。当前不能据此声称素材为团队原创或已获商业授权，商业化需要先完成授权核查。

## 4:00–5:00：验证与落地

我们接下来要验证两件事。第一，学生能否独立完成任务，能否理解反馈并找到复习入口，这通过可用性试点观察。第二，在相同内容、相同学习时间下，讲解通关是否改善迁移任务与延迟测验表现，这需要前测、平行题、盲评和预先确定的分析方案。目前没有可报告的教育效果提升数字。

商业上，我们先验证高校 AI 入门实践课是否需要这样的任务与反馈工具，再确认教师的使用意愿、实际服务成本和付费责任。现在没有真实营收或留存数据，也不把参赛当作市场验证。

AI Master 目前交付的是一个边界明确、能够演示学习过程的原型。今天请评委重点检验：讲解是否真的被检查，客观题是否独立验收，记录是否真实保存，以及学习者能否根据反馈继续练习。谢谢。

## 现场分支

- 模型不可用：说“模型复评暂时不可用，这次讲解不会自动判为通过；可以重试，或明确切回本地练习。客观题仍按标答判分。”不要把本地反馈读成 AI 判断。
- 未通关：说“这次尚未满足条件，我展示失败原因与修订入口。”不修改数据库或跳过条件制造成功。
- 服务故障：说明本机服务异常，转看已有代码和测试记录；静态课程入口不能替代本次持久化功能验收。
- 超时：缩短课程浏览，保留失败反馈、独立测验、刷新恢复和版权边界四项。
