# 现场演示兜底方案（demo-fallback）

> **用途**：答辩 / 巡展现场的后端可用性兜底。对应验收意见 R-106（P1）。
> **为什么是 P1**：巡展评分结构中「**现场演示效果**」占 **50 分**，而主后端绑在一台个人电脑上。
> 本文件是内部演练材料，**不属于评审材料**，不放入提交包。

---

## 1. 风险前提（必须承认）

| 事实 | 后果 |
| :--- | :--- |
| 后端主端 = 本机 `node server/index.js`（8787）+ 樱花隧道（自签证书） | 电脑关机 / 休眠 / 进程崩溃 → 主端直接掉 |
| `scripts/start-backend.ps1` 是**一键启动 + 探活**，不是守护进程 | **掉线不会自动恢复**，必须人工执行（R-002 验收口径） |
| 隧道是外部工具（SakuraFrpLauncher），配置不在仓库内 | 换台机器就归零 |

⇒ 结论：**必须准备"主端掉线也能完整演示"的路径，并在答辩前演练。**

---

## 2. 三条路径（按优先级）

| 路径 | 形态 | 何时用 | 前置条件 |
| :--- | :--- | :--- | :--- |
| **A · 主路径** | 演示机浏览器 → `https://frp-end.com:45695`（自签证书，需放行） | 正常情况 | 本机服务在跑 + 隧道在线 |
| **B · 本机直连兜底** | 演示机浏览器 → `http://127.0.0.1:8787/frontend/learning-center/` | 隧道掉线 / 外网不稳 | 只需本机服务在跑（**不依赖外网**） |
| **C · 只读兜底** | `https://aimaster-studio.github.io/ai-master/` | 后端完全不可用 | 无 |

**B 是最重要的一条**：它**不依赖隧道、不依赖外网**，只要本机服务活着就能跑完整闭环（讲解 → AI 复评 → 测验 → 通关）。
**C 只能演示静态浏览与本地规则降级**（无后端 → 无 AI 复评、无测验判分、无记录落库），**不能**用它演示完整学习闭环。

---

## 3. 演示前 60 秒自检（一条命令）

```bash
node scripts/check-connectivity.mjs --insecure --local-chain
```

**判据（缺一不可）**：

- 隧道 `/api/status` → **200**
- 隧道 `POST /api/explanation` → **`mode:"ai"`**（这是唯一有效的后端判据；`/api/status` 200 不算）
- 本机 8787 `/api/status` → **200**（B 路径可用的前提）

若未全绿，先跑：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/start-backend.ps1
# 退出码：0 成功 / 1 本机未就绪 / 2 隧道未就绪
```

---

## 4. 掉线后 60 秒切换演练（现场执行步骤）

| 时间 | 动作 |
| :--- | :--- |
| 0–10s | 看到「AI 服务暂不可用」**不要慌**——这是 **fail-closed 的刻意设计**，不是崩溃 |
| 10–30s | 跑 `scripts/start-backend.ps1`；若退出码 = 2（隧道未就绪），检查 SakuraFrpLauncher 是否在跑 |
| 30–45s | 浏览器切到 **B 路径**：`http://127.0.0.1:8787/frontend/learning-center/` |
| 45–60s | 复跑 `node scripts/check-connectivity.mjs --insecure --local-chain` 确认 `mode:"ai"` 恢复 |

**切换不需要重启任何前端页面**（B 路径是同源服务，直接换地址即可）。

---

## 5. 现场话术（把故障变成加分项）

- 「我们的 AI 复评是 **fail-closed**：上游不可用时**明确判未通过**，并提示不要以本地规则为准——**不会为了好看而放水**。」
- 「主后端跑在本机 + 自签隧道上，所以我们也准备了**本机直连兜底**，外网断了照样能演示完整闭环。」
- 不要声称"永不掉线"。**主动披露边界 + 展示兜底**，比被评委问出来强。

## 6. 演练要求（答辩前必须完成）

- [ ] 完整演练 **≥ 2 次**，其中 **1 次故意杀掉后端进程**，走一遍第 4 节的 60 秒切换
- [ ] 演练记录（时间 / 结果 / 卡点）写入 `devlog/`
- [ ] 确认演示机浏览器**已放行**自签证书（首次会弹「不是私密连接」，需手动继续）
