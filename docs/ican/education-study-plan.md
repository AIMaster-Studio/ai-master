# 教育效果研究计划

状态：研究方案，尚未招募、实施或产生结果。所有时间点和指标均为计划。

## 研究问题

在课程内容与学习时间相同的条件下，增加“自己讲解、独立客观测验、纠错与复习”是否改善大学生对 AI 基础及 RAG 概念的迁移应用与延迟保持？先评价整套流程；没有足够样本和设计条件时，不宣称能单独归因于角色动画或某一反馈机制。

## 第一阶段：可用性与内容试点

邀请符合目标背景的参与者，在知情同意后完成一个模块。观察能否独立找到任务、理解反馈、修订解释、完成测验和找到复习记录。记录卡点、误解、退出理由与用时，询问已有知识和辅助工具使用情况。

试点用于修订流程、排除题目歧义与检查数据采集。人数按背景覆盖和问题暴露情况安排，不把方便招募的小样本当作教育效果证明。先邀请领域教师审查概念、标准答案和迁移题，并检查认知标注一致性。第七章空正文和未经核实的历史数字不得进入试验材料。

## 第二阶段：效果研究

| 设计项 | 预先确定的做法 |
| --- | --- |
| 人群 | 目标课程中的大学生，记录相关先修、年级和既有 AI 工具使用经验 |
| 分组 | 条件允许时按前测水平分层随机分配；若按班级分配，分析考虑班级聚类 |
| 对照 | 相同课程内容、练习总时长与访问设备，采用普通阅读及常规练习；明确两组差异 |
| 前测 | 使用未出现在练习中的基础概念与应用题，检验起点差异 |
| 主要结局 | 预先选定一个延迟迁移任务综合分，使用独立平行题和事先固定评分规则 |
| 时间点 | 学习前、学习后；延迟测可选择 7 天或 14 天之一，在实施前固定，不按结果选择 |
| 次要结局 | 即时测验、错误类型、自主修订质量、持续使用与主观负担；不替代主要结局 |
| 评分 | 评分者尽可能不知道分组；开放题双人评分，先用锚定样例校准并报告一致性 |
| 样本 | 根据主要指标、最小有意义差异、方差估计、功效与退出率计算，不任意指定人数 |
| 分析 | 预先登记主要比较、协变量、缺失处理和排除条件；报告效应量与置信区间及全部主要结果 |

若只能获得小样本，报告可行性、描述统计和不确定区间，避免仅凭显著或不显著判断有效或无效。重复查看结果、改主要指标或按结果调整样本都应披露。所有方案变更记录日期与原因。

## 控制混杂与作弊

两组使用相同版本的教学内容，控制或记录学习时间、教师支持和额外工具使用。练习题与最终题分离，使用平行题考察新场景；不将平台通关记录直接作为主要教育结局。若允许外部 AI，须两组规则一致并记录；若不允许，说明实际监督条件及仍可能存在的代答风险。

模型评审必须固定提供商、模型标识、提示版本和设置，并保存脱敏反馈来源。模型可能更新或不稳定，因此开放题正式研究结果优先由预设人工规则评定。角色陪伴属于流程的一部分；要单独检验其作用，应另设研究，不能从整套产品效果反推。

## 数据与参与者保护

参与不应影响课程成绩与教师评价；告知研究目的、采集字段、保存地点、保留时长、访问者以及退出与删除流程。使用研究编号，身份映射分开保管，仅采集回答、必要背景、时间和事件记录。需要院校研究伦理审查或批准时，先取得所需文件再招募。

如启用远程模型，事先说明讲解内容与必要上下文将发送到所配置服务商，核对服务商条款和实际字段，不提交敏感资料。原型“本机保存”不能替代研究治理；导出、删除、去标识化流程必须在试点前实际测试。匿名化前不公开原始学生回答。

## 相关文献及使用边界

- Roediger, H. L., & Karpicke, J. D. (2006). Test-enhanced learning: Taking memory tests improves long-term retention. *Psychological Science, 17*(3), 249–255. [DOI](https://doi.org/10.1111/j.1467-9280.2006.01693.x)。支持检索练习研究动机，不提供 AI Master 的效果量。
- Cepeda, N. J., et al. (2006). Distributed practice in verbal recall tasks: A review and quantitative synthesis. *Psychological Bulletin, 132*(3), 354–380. [DOI](https://doi.org/10.1037/0033-2909.132.3.354)。讨论分散练习；不能直接证明本原型复习间隔最优。
- Krathwohl, D. R. (2002). A revision of Bloom's taxonomy: An overview. *Theory Into Practice, 41*(4), 212–218. [DOI](https://doi.org/10.1207/s15430421tip4104_2)。用于描述可观察认知任务，不是学习效果评级工具。

前两篇 DOI 元数据已于 2026-09-05 通过 Crossref 核对；文献引用不表示已复现其研究。正式试验前还需审阅与生成式 AI、自我解释、反馈和目标人群相关的研究，明确与本方案的可比条件。
