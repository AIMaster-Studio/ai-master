## 方法局限（主动声明，不扩大结论）

1. **自选样本，非随机抽样**：按投放渠道触达，存在同班/同群聚集效应；
2. **"讲师采购意愿"是身份假设题**：受访者以模拟讲师身份作答，20 人中**无经核实的真实讲师**；该数字只能表达"目标买家画像下的意愿倾向"，不是真实采购承诺；
3. **未设置价格锚点/金额区间**：不能回答"愿意付多少钱"，仅能反映付费方式偏好；
4. **n=20 小样本**：仅作需求探索，不做统计推断，与 21 组双盲一样属于"探索性证据"，不声称达到显著水平；
5. **匿名采集，无签到/身份核验**：无法排除重复作答或随意作答。
