## 容易误用的表述

| 不应采用 | 可采用 |
| --- | --- |
| 完整商业化平台，已经具备所有后端能力 | 可运行的本机学习原型，具体验收范围见测试记录 |
| 五十七个知识点全部完整、全部掌握 | 五十七个课程节点，正文与考核覆盖情况逐项标注 |
| AI 精准判断学生真正理解 | 规则与可选模型提供练习反馈，存在误判，另设独立客观题 |
| 学习效果提高某个百分比 | 尚无本项目效果数据，已有研究计划 |
| 所有素材 MIT，可放心商用 | 代码与素材许可分别核查；dsh-pet 素材写明禁止商用 |
| 原创鲸鱼娘与原创九十七动作 | 集成并保留上游角色与已有动作，标注第三方来源 |
| 已经通过学校认定、评委高分验证 | 用户选择创新赛道，正式审核和真实评审记录尚未提供 |
| 手机端流畅、低端设备适配完成 | 仅报告实际测试设备、浏览器和视口的结果 |
| 本地保存，所以任何数据都不会出机 | 学习记录可存本机 SQLite 或远程 Turso；开启远程模型后相关输入会发往服务商 |
| 已经支持语义检索 | 默认是本机哈希嵌入，只做词面重合；配了远程嵌入模型才是语义检索，且换模型必须重建索引 |
| 讲解复评能判断学生是否真正理解 | 复评基于课程证据并要求模型回报引用号，引用号会被复核；但复核只能确认引用真实存在，不能确认结论被证据支持，也仍不能杜绝背题与代答 |
| 记忆会归纳你的学习风格 | L2/L3 是计数与比例的确定性聚合，不做语义归纳，不会产生「你偏好类比式讲解」这类推断 |
| 记忆能跨设备同步 | 记忆是本机文件，按用户隔离，不存在云端副本 |
| 技能包可扩展执行能力 | 技能是声明式文本、不执行代码；本仓库无沙箱，故也不提供代码执行工具 |

## 课程事实审校队列

本次没有重写整套历史课程。需要优先复核的内容包括：闭源模型参数与训练数据估计、训练时间线、将 token 定义为“最小语义单位”、提示效果倍数、角色提示激活特定子网络的说法、直接 API 只能单轮的绝对表述，以及随工具版本变化的安装与配置示例。审校时使用官方文档或原始论文，记录日期与适用版本；未核实数字不进入新增客观题标准答案。
