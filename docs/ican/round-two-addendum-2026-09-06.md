# 第二轮评委整改补充证据

日期：2026-09-06。本文是对第二轮评审问题的补充记录，结论只覆盖当前仓库和本机原型。

## 本轮可复核改动

| 评委关注点 | 处理与证据 |
| --- | --- |
| AI 故障时状态是否矛盾 | `server/ai-review.js` 在远程服务超时、返回错误或 schema 不合法时返回 `mode: fallback-local`，`accepted` 与检查列表均来自同一组本地七项检查，不再追加伪造的失败 AI 检查项。 |
| 提示注入是否有边界 | 评审提示明确把学生文本标为不可信材料，并以 JSON 数据字段传入；`tests/learning-server.test.js` 的隔离测试检查 system/user 角色、原文保留和恶意文本不进入 system 规则。 |
| 复习间隔是否跳过首次复习 | `server/index.js` 的 `reviewDelayDays` 将连续答对次数映射为 1、3、7、14、30 天；答错会清零连续次数并安排 1 天后复习。该映射是产品策略，不宣称为研究得出的最优公式。 |
| 本轮测试证据 | `npm run test:learning`：31 项测试通过，0 项失败。 |

## 模型路径的对外表述

1. 未配置模型：只使用本地七项完整性筛查，结果标记为 `local`。
2. 已配置模型且调用成功：在本地筛查通过后进行结构化复评，结果标记为 `ai`；客观题仍由预设答案独立判分。
3. 已配置模型但调用失败：结果标记为 `fallback-local`，明确提示没有完成 AI 语义复评；本地筛查失败时不会被降级路径绕过。

## 仍需保留的边界

- 0.55、0.65 等相似度阈值和关键词规则是当前原型的工程参数，尚无代表性语料统计依据，不能表述为科学最优值。
- `factualCorrect` 是可选模型的自评字段，不能替代教师或独立事实核验；客观题门槛用于降低单一路径误判。
- 题库、课程事实、学校确认、真实用户样本和学习效果仍需单独审校或研究，不能由本轮自动化测试推导。
- 鲸鱼娘形象及动作继续保留在 `third_party/dsh-pet/dsh-pet`；上游素材说明限制商业使用，商业化前必须取得适用授权。
