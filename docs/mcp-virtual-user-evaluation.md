# Evaluation with AI-generated test samples — 2026-09-18

> ## ⚠️ Scope statement — read before quoting any number
>
> **Recall@1 = 0.52, Recall@3 = 0.83, MRR = 0.664 and the review false positive rate of 24%
> were all produced by a non-human process**: the queries were generated by paraphrase
> rules/AI from course text, and the review labels come from two rule-based scorers, not
> from people. They measure how the pipeline behaves on **AI-generated test samples**.
> They are **not evidence of model effectiveness, retrieval quality for real students, or
> learning gains**, and **must not be cited externally as such** (competition materials,
> slides, README, marketing). Internally they are useful only as regression baselines.
>
> The term "virtual user" was used in earlier drafts and has been replaced with
> "AI-generated test samples" throughout, because "user" wrongly suggests a person.

The user approved generating test samples by AI and rules. Everything below is AI or rule
generated. It is NOT real student data and the raters are NOT independent humans. Labels
in the datasets state this, and no figure here may be presented as a human study.

## 1. Retrieval benchmark, 100 queries, run against production

Queries were derived from the real 57 course nodes in three paraphrase styles, gold label
being the source node. Executed against https://ai-master-backend.vercel.app, all 100
returned HTTP 200 with no empty result sets.

| metric | value |
| --- | --- |
| Recall@1 | 0.52 |
| Recall@3 | 0.83 |
| Recall@5 | 0.86 |
| MRR | 0.664 |
| empty rate | 0 |
| latency p50 / p95 | 340 ms / 774 ms |

Recall@1 of 0.52 is weak: for roughly half the queries the best chunk is not ranked first,
even though the correct node is usually reachable by rank 3. Retrieval currently runs
without an embedding provider, so this is lexical matching only; adding embeddings and a
reranker is the obvious next step and remains unimplemented.

Honest accounting detail: 16 retrieved titles are chapter-level documents outside the 57
nodes. They are kept in the ranking under a nongold:: id rather than dropped, because
dropping them would promote later hits and inflate Recall@1 and MRR.

## 2. Explanation review, 200 AI-generated samples, two rule-based scorers

200 explanations were generated from real node content, half faithful and half carrying a
deterministic injected defect (wrong chapter, absolute claim, fabricated statistic,
contradiction). Two rule-based scorers with deliberately different heuristics labelled
each sample; disagreements were adjudicated against the injected ground truth.

| metric | value |
| --- | --- |
| accuracy | 0.86 (95% CI 0.805-0.901) |
| precision | 0.80 |
| recall | 0.96 |
| F1 | 0.873 |
| false positive rate | 0.24 (95% CI 0.167-0.332) |
| raw agreement between the two rule-based scorers | 0.77 |

The weakness is the 24% false positive rate: the grounding gate accepts about a quarter of
defective explanations, mostly wrong chapter attribution and unsourced precise statistics.
Raw agreement of 0.77 is agreement between two rule sets and is not inter-rater reliability.

## 3. Factual consistency screening, all 57 nodes

Two bugs were found and fixed before the numbers meant anything. First, the screening ran
over knowledge-universe summaries truncated to about 200 characters, which produced a
meaningless zero findings; it now reads the full chapter_NN.json knowledge_points content,
median 871 characters. Second, an HTML rule flagged all 57 nodes, since HTML is the
intended storage format; it now only flags escaped entities that would render literally.

Result after the fixes: 57 nodes screened, 1 node with a low severity finding.

tests/fact-screening.test.js locks this in with three tests: the report covers 57 nodes
with full-length content, every rule fires on known-bad text, and clean technical prose
does not trip the rules. Without those, a clean screening result would be unfalsifiable.

## What this does not establish

No real learner ever used these paths. Machine screening cannot certify that a claim is
true, only that no rule fired; subject-matter review by a qualified human is still
required before any external submission. The 57/57 structural coverage figure remains a
coverage measure, not a factual verification. Skills and agent storage remain ephemeral.
