# AI Master 创新赛道原型改造

用户授权两小时内自主完成可运行初版，不再问答。明确保留鲸鱼娘原形象、全部已有动作和第三方署名。当前仓库为前端复现版及 Electron 扩展，不能宣称已经交付私有 Flask 完整版。

## 目标

面向学习 AI 通识与 RAG 入门的大学生，把学习中心变成「讲解通关」工作台。核心演示：基础诊断 → 选择目标与节奏 → 学习 → 自己讲解 → 客观题验收 → 通关 → 错题与间隔复习 → 导出真实学习记录。鲸鱼娘在思考、答题和通关时响应，保留用户喜爱的视觉资产。

## 实施决策

- 沿用原生前端和本地资源，不重做课程与 3D 星海。增加 Node 24 本地服务、SQLite 数据存储和同源 API。默认本机访问，支持浏览器访客档案与可选本地账号，不声称云同步。
- 内容先扎实覆盖 RAG、Agent 和通识共用的核心任务。其余 57 个课程节点保持可访问，认知层级是团队教学设计标注，不等于教育效果验证。
- 讲解先做重复、空泛和主题检查；配置模型时再做结构化 AI 复评。未配置或失败必须明确返回本地练习状态，不伪装 AI。客观题按确定标答判分，独立于 LLM；讲解条件与测验 >= 75% 均满足才能通关。
- 支持重读、修订、失败重试、刷新恢复、记录导出和到期复习。原静态部署继续可访问课程；新服务为本次答辩演示版本。
- 产品名采用「讲解通关」，不借新的名人标签。创新赛道按用户已说明事实写，不虚构学校盖章或比赛评分。
- 无真实用户、教育效果、低端真机、模型准确率、营收与原创资产的虚构数据。
