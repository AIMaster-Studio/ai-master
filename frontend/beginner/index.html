豆包

中文问答与写作

适用场景
解释陌生概念、整理想法、起草中文短文。
核心功能
连续追问、文字改写和摘要；其他输入方式以账号当前界面为准。
三步上手
  1. 打开对话入口，按页面提示登录。
  2. 输入「用三句话解释大语言模型，给我一个生活例子」。
  3. 追问一个反例，把答案中能核实的事实逐项核对。
门槛
需要可用网络和相应账号；当前免费范围及额度以页面为准。
不适用情况
需要有出处的精确数据时，需另行核对原始来源。
入口状态
官方入口；登录后界面、额度与功能需以当前账号显示为准。 内容整理于 2026-09-16。

ChatGPT

通用对话与材料处理

适用场景
构思文章、分析已授权材料、迭代复杂任务。
核心功能
对话、写作与材料分析；文件和多模态工具的可用性取决于方案与账号。
三步上手
  1. 打开官方入口，确认所在地区及网络可访问。
  2. 新建对话，说明场景、受众、目的和希望的格式。
  3. 提供一段不含敏感信息的示例，请它按验收标准修改。
门槛
部分能力需要登录或付费方案；当前网络未完成访问核实。ChatGPT 订阅与 API 计费分开。
不适用情况
没有可用入口、需要直接操作受限内网系统或必须保证答案正确的任务。
入口状态
官方入口；当前环境网络访问待核实。 内容整理于 2026-09-16。

文心千帆

模型服务与开发工作台

适用场景
把模型接入自己的应用，比较模型输出并管理调用。
核心功能
百度智能云的模型开发与调用入口；具体模型和应用能力按当前控制台确认。
三步上手
  1. 进入官方产品页，按引导登录百度智能云。
  2. 先在控制台体验一个小问题，记录模型名和输出。
  3. 需要接程序时再按官方示例发起一次调用，核对用量。
门槛
可能需要实名认证、开通服务及费用；先确认计费和配额。密钥仅配置在服务端环境中。
不适用情况
只想立即闲聊且不想配置云服务的新手，先从对话工具开始。
入口状态
官方入口；登录后界面、额度与功能需以当前账号显示为准。 内容整理于 2026-09-16。

扣子

搭建可重复使用的助手

适用场景
把固定规则、已授权资料与流程组成一个助手。
核心功能
智能体编排、知识库和工作流；模块名称与权限按当前界面确认。
三步上手
  1. 登录后新建一个最小助手，写清它服务谁和做什么。
  2. 加入一份自己有权使用的短资料，并写明无依据时应说明。
  3. 在预览区各问一个资料内和资料外的问题，检查出处与边界。
门槛
需要账号和网络；模型、插件及运行额度可能计费。上传前移除隐私、密钥和未授权内容。
不适用情况
任务还没明确，或要求未经复核自动执行高影响操作的场景。
入口状态
官方入口；登录后界面、额度与功能需以当前账号显示为准。 内容整理于 2026-09-16。

阿里云百炼

模型体验与 API

适用场景
在代码中调用模型，并观察质量、用量和成本。
核心功能
模型体验、API 调用、调用用量管理；以所选模型的官方文档为准。
三步上手
  1. 登录阿里云控制台，先查看开通条件、价格及可用额度。
  2. 在模型体验中发送一个短请求，核对输出。
  3. 按官方示例调用一次 API，再查看响应中的用量与账单。
门槛
需云账号，可能需实名认证；调用可能计费，用量统计可能延迟。不要把密钥放入网页或提交到仓库。
不适用情况
尚未明确要解决什么问题，或不准备管理云端调用成本时。
入口状态
官方入口；登录后界面、额度与功能需以当前账号显示为准。 内容整理于 2026-09-16。

AI Master

学完之后动手验证

适用场景
把读过的概念变成自己的讲解、作品和可核对的记录。
核心功能
课程知识卡、对应实践、讲解通关与测验；完整学习记录依赖运行方式。
三步上手
  1. 从课程总览选择一个知识点，读完后点「去做实践」。
  2. 按步骤完成任务，保存自己的输入、输出和结论。
  3. 回到学习中心，用自己的话讲解，再完成测验与复习。
门槛
阅读和实践入口可通过本站访问；本地完整服务需按 README 启动。AI 复评是否可用取决于模型配置。
不适用情况
把测验分数当成真实工作能力证明，或要求平台代替自己完成全部实践。
入口状态
项目内入口，可用性由本地验收检查。 内容整理于 2026-09-16。
